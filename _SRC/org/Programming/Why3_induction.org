* Proving by induction

There are different ways to prove something, in math one of them is proving by induction. Its
idea is: prove that a statement is true for every natural number ~n~.

- *Identify the cases.*
  The theorem, lemma, or claim usually has many cases. We want to prove that the statement is true for all of them.
- *Number the cases.* We describe the cases using a natural number ~n~.
  For example, if the cases are ~2x, 4x, 6x, 8x, ...~ we can describe the ~n~-th case as ~2*n*x~.
  So instead of proving infinitely many separate cases, we can talk about them using one number ~n~.
- *Prove the base case.* We prove that the statement is true for the first case, usually ~n=0~
  or ~n=1~ (but it can be any).
- *Prove the induction step.* We prove a general rule:
  *I͟f͟ t͟h͟e͟ s͟t͟a͟t͟e͟m͟e͟n͟t͟ i͟s͟ t͟r͟u͟e͟ f͟o͟r͟ s͟o͟m͟e͟ c͟a͟s͟e͟ n͟,͟ t͟h͟e͟n͟ i͟t͟ i͟s͟ a͟l͟s͟o͟ t͟r͟u͟e͟ f͟o͟r͟ t͟h͟e͟ n͟e͟x͟t͟ c͟a͟s͟e͟,͟ n͟+͟1͟. and
  EVERY case has previous, next case, so it means ALL cases are true* ("next is true"
  automatically means "ALL" after some zero, initial case)
  The important word is some. We are not proving only that case ~n=5~ leads to case ~n=6~. We prove
  the rule for every possible n: ~P(n) => P(n+1)~
- *Put the two parts together.* We know the first case is true: ~P(1)~ and we know that every
  true case leads to the next true case: ~P(n) => P(n+1)~. Therefore: ~P(1) => P(2) => P(3)...~
- So: *every case is true.*:

#+begin_example
P(1) => P(2)
P(2) => P(3)
P(3) => P(4)
...
P(n) => P(n+1)
#+end_example

#+begin_quote
PROVE THE FIRST CASE, THEN PROVE THAT EVERY CASE (IF IT IS TRUE) LEADS TO THE NEXT
CASE. THEREFORE ALL CASES ARE TRUE.
#+end_quote

Again, we don't prove that ~P(n)~ is true, we prove that *IF* ~P(n)~ is true, then ~P(n+1)~ is
true, but it does not prove that ~P(n)~ is true, maybe *IT IS NOT*. We prove only logical
connection between them - "IF one true, the next (any) true too" . But... if among them we see
at least one case true - then ALL are:

#+begin_example
          oh, true!
             |
            \v/ 
   o -> o -> O -> o -> ... -> o -> o -> o
     |      / \
     |
     `-- if the previous is true
         then the next is true
#+end_example

but we select 0-th because it is more mathematically "regular".

See [[https://en.wikipedia.org/wiki/Mathematical_induction][more in Wikipedia]].

* Induction in Why3

Lets prove this formula:

\begin{aligned}
P(n \in \mathbb{N}): 0 + 1 + 2 + \ldots + n = \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \text{ , formula (1)}
\end{aligned}

It is proven by induction as...

/*Induction case*/ if want to prove that IF it is true for some ~n~ (some... hmmm, let's
call it ~k~, i.e., when ~n = k~), then it is true for the next (i.e., ~k + 1~). What do we
know? We know only that formula (1). We chose some PARTICULAR NUMBER among the series natural
numbers, we designed it as ~k~. The formula (not proven yet!) is the same (1) but imagine the
particular ~k~ instead of abstract ~n~. OK. The step is to prove that ~P(k+1)~ is true too -
when ~P(k)~ is true: ~P(k) => P(k+1)~. How? Look:

\begin{aligned}
\text{For k :   } 0 + 1 + \ldots + k = \frac{k(k+1)}{2} \\
\text{For the next, i.e., k + 1 is :   } 0 + 1 + \ldots + k + (k + 1) = ?
\end{aligned}

Well, ~?~ is our formula (1) plus this new addend - ~(k + 1)~:

\begin{aligned}
0 + 1 + \ldots + k + (k + 1) = \frac{k(k+1)}{2} + (k + 1)
\end{aligned}

After simplification this formula became:

\begin{aligned}
0 + 1 + \ldots + k + (k + 1) = \frac{(k+1)((k+1)+1)}{2}
\end{aligned}

If to rename ~(k + 1)~ as some... ~X~: $\frac{X(X+1)}{2}$, wow! We see again the formula (1) !
What is our conclusion after this mathematical exercise? It is:

#+begin_quote
If formula (1) is true (we don't know: maybe it is not!), but if (1) is true, for some /k/ then
it is true for /k+1/ too because IT IS THE SAME FORMULA AGAIN! So, we proved that if ~P(k)~ is
true then ~P(k + 1)~ will be true too.
#+end_quote

/*Base case*/ ok, now lets select the "base" case - ~n=0~ (or 1, etc):
   
\begin{aligned}
\text{Base case : }P(0) = \frac{0(0+1)}{2} = 0
\end{aligned}

#+begin_quote
Conclusion: Since both the base case and the induction step have been proved as true, by
mathematical induction the statement ~P(n)~ holds for every natural number ~n ≥ 0~ !
#+end_quote

Proven! This is the method, approach of math. induction - an example of its usage.

See [[https://en.wikipedia.org/wiki/Mathematical_induction#Sum_of_consecutive_natural_numbers][more on Wikipedia]].

In math we had a sum equals to... In Why3 we should express the sum in some way, we did it

| mathematics        | Why3                      |
|--------------------+---------------------------|

So, the sum is expressed through a recursion, OK, but the result (right hand side) of the
formula ... Why3 cannot prove it by default!

** Lemma with a body

We wrote:

#+begin_example
module MySum

  use int.Int
  use int.EuclideanDivision

  let rec function sum (n: int) : int
    requires { n>=0 }
    variant { n }
  =
    if n = 0 then 0
    else n + sum (n - 1)

  let rec lemma sum_formula (n: int)
    requires { n >= 0 }
    ensures { sum n = div (n * (n + 1)) 2 }
    variant { n }
  =
    if n = 0 then
      ()
    else
      sum_formula (n - 1)

end
#+end_example

And the proving now:

#+begin_example
$ why3 prove -Pz3 MySum1.mlw
File MySum1.mlw:
Goal sum'vc.
Prover result is: Valid (0.00s, 431 steps).

File MySum1.mlw:
Goal sum_formula'vc.
Prover result is: Valid (0.00s, 6485 steps).
#+end_example

How does it prove the formula (1) by induction?!

First, the "lemma" is our theorem, our formula (1). Second, it has "a contract": precondition,
postcondition and an argument ~n~:

#+begin_example
  requires { U(n) }       \_____  U(n) -> V(n): Assuming U(n), prove V(n).
  ensures { V(n) }        /
#+end_example

~U~ is ~n ≥ 0~. And the ~V~ is exactly $\frac{n(n+1)}{2}$ ! But... our lemma is not only
proposition-based, it has a body. And the body is this:

#+begin_example
    if n = 0 then
      ()
    else
      sum_formula (n - 1)
#+end_example

So, the base case is ~n=0~ - the lemma-with-a-body returns ~()~, i.e., a unit which means
"proven!", then - the induction step: else - follow recursion. By the way, this can be
rewritten lesser explicit and shorter, it is the same:

#+begin_example
    if n > 0 then
      sum_formula (n - 1)
#+end_example

What does Why3 do with all these? Using induction it has to check that ~P(n) => P(n+1)~ and to
find the base case. Our lemma is:

\begin{aligned}
P(n) \equiv \sum_{i=1}^{n} i = \frac{n(n+1)}{2}
\end{aligned}

~P(n-1)~ is, then:

\begin{aligned}
P(n - 1) \equiv \sum_{i=1}^{n - 1} i = \frac{(n-1)n}{2}
\end{aligned}

Two different propositions. We can assume $P(n - 1) = \sum_{i=1}^{n - 1} i$ as true - it will be our
/induction hypothesis/. Our goal is ~P(n)~ which is $\sum_{i=1}^{n} i = \frac{n(n+1)}{2}$ (the
postcondition of our lemma is).

From the recursive definition of the sum (~let rec function sum~) Why3 knows that when ~n > 0~:

\begin{aligned}
\sum_{i=1}^{n} i = n + \sum_{i=1}^{n - 1} i
\end{aligned}

and Why3 use it in our goal ~P(n)~, replacing $\sum_{i=1}^{n} i$ by $n + \sum_{i=1}^{n - 1} i$ :

\begin{aligned}
n + \sum_{i=1}^{n - 1} i = \frac{n(n + 1)}{2}
\end{aligned}

Why3 uses the $\sum_{i=1}^{n - 1} i$ from the induction hypothesis and:

\begin{aligned}
n + \frac{(n - 1)n}{2} = \frac{n(n + 1)}{2}
\end{aligned}

This is passed to SMT solver and it easy proves it (~n~ is in a numerical domain - a task as for SMT).

Conceptually, the induction step is ~P(n - 1) => P(n)~, but Why3 doesn't necessarily hand Z3
one giant formula literally written in this way. Instead, Why3 creates a /verification
condition/ (VC) with ~P(n - 1)~ as an assumption $P(n-1) \vdash P(n)$ which means:

#+begin_quote
Assuming ~P(n - 1)~ as true, prove ~P(n)~
#+end_quote

Bigger picture:

#+begin_example

 ## 2. What does the induction hypothesis say?

 Why3 gives us:

```
H:
sum(n-1) = div((n-1)n, 2)
```

 That is **`P(n-1)`**.

 We are allowed to assume it.

 We are NOT trying to prove it again.

 ## 3\. What is our actual goal?

 Our goal is:

```
sum(n) = div(n(n+1), 2)
```

 That's **`P(n)`**.

 Now use the definition of `sum`.

 Because `n > 0`:

```
sum(n) = n + sum(n-1)
```

 So our goal:

```
sum(n) = div(n(n+1),2)
```

 becomes:

```
n + sum(n-1) = div(n(n+1),2)
```

 Now use the induction hypothesis:

 Substitute that into the goal:

 **That is the formula you asked about.**

 It is what's left to prove **after we have already used `P(n-1)`**.

 # 5\. Where is the implication `P(n-1) → P(n)`?

 This is the really important part.

 Conceptually, the induction step is:

 $$
P(n-1) \Rightarrow P(n)
$$

 Why3 doesn't necessarily hand Z3 one giant formula literally written as:

```
P(n-1) -> P(n)
```

 Instead, Why3 creates a **verification condition with `P(n-1)` as an assumption**.

 In logical notation, it is equivalent to:

 $$
P(n-1) \vdash P(n)
$$

 which means:

 > Assuming `P(n-1)`, prove `P(n)`.

 And in classical logic:

 $$
P(n-1) \vdash P(n)
$$

 is equivalent to:

 $$
P(n-1) \rightarrow P(n)
$$

 So the implication is there — it's just represented in the VC as a **hypothesis/context plus a
 goal**, rather than necessarily as an explicit `→`.

 Your IDE showed exactly that:

```
Hrec : forall n1:int.
       n1 < n ->
       n1 >= 0 ->
       sum n1 = div (...) 2

Goal:
       n >= 0 ->
       sum n = div (...) 2
```

 Once the relevant hypotheses are introduced, conceptually you get:

```
ASSUME:

P(n-1)

PROVE:

P(n)
```

 That's the induction implication.

 # 6\. And there are actually TWO different proofs happening

 This is probably the source of the confusion.

 ### Proof A — induction hypothesis

 Why3 establishes/provides:

```
P(n-1)
```

 as an **assumption**.

 It does not ask Z3 to prove it again at this point.

 ### Proof B — induction step

 Z3 proves:

```
P(n-1) → P(n)
```

 but operationally it gets this as:

```
Assume P(n-1)
Prove P(n)
```

 After unfolding and substitution, the remaining arithmetic is:

```
n + div((n-1)n,2)
=
div(n(n+1),2)
```

 So:

```
                 P(n-1)
                    │
                    │ assumption
                    ▼
             ┌──────────────┐
             │   Why3 VC    │
             │              │
             │ prove P(n)   │
             └──────┬───────┘
                    │
          unfold sum(n)
                    │
                    ▼
       n + sum(n-1) = RHS
                    │
           use P(n-1)
                    │
                    ▼
       n + div((n-1)n,2) = RHS
                    │
                    ▼
                   Z3
                    │
                    ▼
                  TRUE
```

 That's the whole induction step.

 ## And one final subtlety

 When I previously said:

 > "Z3 proves `n + div(...) = div(...)`"

 that's shorthand.

 More precisely, **Why3 gives Z3 a VC containing the relevant assumptions**, including the induction hypothesis and facts about `n`.

 So Z3 isn't proving that equality for arbitrary integers with no assumptions. It's proving it **under the assumptions generated by Why3**.

 That's why looking at the **full VC in the IDE** is so useful. It shows you exactly what Z3 is being asked to prove, rather than the simplified mathematical story we tell when explaining it.
