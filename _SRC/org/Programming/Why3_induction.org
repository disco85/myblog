* Proving by induction

There are different ways to prove something, in math one of them is proving by induction. Its
idea is: prove that a statement is true for every natural number ~n~.

- *Identify the cases.*
  The theorem, lemma, or claim usually has many cases. We want to prove that the statement is true for all of them.
- *Number the cases.* We describe the cases using a natural number ~n~.
  For example, if the cases are ~2x, 4x, 6x, 8x, ...~ we can describe the ~n~-th case as ~2*n*x~.
  So instead of proving infinitely many separate cases, we can talk about them using one number ~n~.
- *Prove the base case.* We prove that the statement is true for the first case, usually ~n=0~
  or ~n=1~ (but it can be any).
- *Prove the induction step.* We prove a general rule:
  *I͟f͟ t͟h͟e͟ s͟t͟a͟t͟e͟m͟e͟n͟t͟ i͟s͟ t͟r͟u͟e͟ f͟o͟r͟ s͟o͟m͟e͟ c͟a͟s͟e͟ n͟,͟ t͟h͟e͟n͟ i͟t͟ i͟s͟ a͟l͟s͟o͟ t͟r͟u͟e͟ f͟o͟r͟ t͟h͟e͟ n͟e͟x͟t͟ c͟a͟s͟e͟,͟ n͟+͟1͟. and
  EVERY case has previous, next case, so it means ALL cases are true* ("next is true"
  automatically means "ALL" after some zero, initial case)
  The important word is some. We are not proving only that case ~n=5~ leads to case ~n=6~. We prove
  the rule for every possible n: ~P(n) => P(n+1)~
- *Put the two parts together.* We know the first case is true: ~P(1)~ and we know that every
  true case leads to the next true case: ~P(n) => P(n+1)~. Therefore: ~P(1) => P(2) => P(3)...~
- So: *every case is true.*:

#+begin_example
P(1) => P(2)
P(2) => P(3)
P(3) => P(4)
...
P(n) => P(n+1)
#+end_example

#+begin_quote
PROVE THE FIRST CASE, THEN PROVE THAT EVERY CASE (IF IT IS TRUE) LEADS TO THE NEXT
CASE. THEREFORE ALL CASES ARE TRUE.
#+end_quote

Again, we don't prove that ~P(n)~ is true, we prove that *IF* ~P(n)~ is true, then ~P(n+1)~ is
true, but it does not prove that ~P(n)~ is true, maybe *IT IS NOT*. We prove only logical
connection between them - "IF one true, the next (any) true too" . But... if among them we see
at least one case true - then ALL are:

#+begin_example
          oh, true!
             |
            \v/ 
   o -> o -> O -> o -> ... -> o -> o -> o
     |      / \
     |
     `-- if the previous is true
         then the next is true
#+end_example

but we select 0-th because it is more mathematically "regular".

See [[https://en.wikipedia.org/wiki/Mathematical_induction][more in Wikipedia]].

* Induction in Why3

Lets prove this formula:

\begin{aligned}
P(n \in \mathbb{N}): 0 + 1 + 2 + \ldots + n = \sum_{i=1}^{n} i = \frac{n(n+1)}{2} \text{ , formula (1)}
\end{aligned}

It is proven by induction as...

/*Induction case*/ if want to prove that IF it is true for some ~n~ (some... hmmm, let's
call it ~k~, i.e., when ~n = k~), then it is true for the next (i.e., ~k + 1~). What do we
know? We know only that formula (1). We chose some PARTICULAR NUMBER among the series natural
numbers, we designed it as ~k~. The formula (not proven yet!) is the same (1) but imagine the
particular ~k~ instead of abstract ~n~. OK. The step is to prove that ~P(k+1)~ is true too -
when ~P(k)~ is true: ~P(k) => P(k+1)~. How? Look:

\begin{aligned}
\text{For k :   } 0 + 1 + \ldots + k = \frac{k(k+1)}{2} \\
\text{For the next, i.e., k + 1 is :   } 0 + 1 + \ldots + k + (k + 1) = ?
\end{aligned}

Well, ~?~ is our formula (1) plus this new addend - ~(k + 1)~:

\begin{aligned}
0 + 1 + \ldots + k + (k + 1) = \frac{k(k+1)}{2} + (k + 1)
\end{aligned}

After simplification this formula became:

\begin{aligned}
0 + 1 + \ldots + k + (k + 1) = \frac{(k+1)((k+1)+1)}{2}
\end{aligned}

If to rename ~(k + 1)~ as some... ~X~: $\frac{X(X+1)}{2}$, wow! We see again the formula (1) !
What is our conclusion after this mathematical exercise? It is:

#+begin_quote
If formula (1) is true (we don't know: maybe it is not!), but if (1) is true, for some /k/ then
it is true for /k+1/ too because IT IS THE SAME FORMULA AGAIN! So, we proved that if ~P(k)~ is
true then ~P(k + 1)~ will be true too.
#+end_quote

/*Base case*/ ok, now lets select the "base" case - ~n=0~ (or 1, etc):
   
\begin{aligned}
\text{Base case : }P(0) = \frac{0(0+1)}{2} = 0
\end{aligned}

#+begin_quote
Conclusion: Since both the base case and the induction step have been proved as true, by
mathematical induction the statement ~P(n)~ holds for every natural number ~n ≥ 0~ !
#+end_quote

Proven! This is the method, approach of math. induction - an example of its usage.

See [[https://en.wikipedia.org/wiki/Mathematical_induction#Sum_of_consecutive_natural_numbers][more on Wikipedia]].

\begin{aligned}

postcondition of our lemma is).

\begin{aligned}

\end{aligned}

\begin{aligned}

\end{aligned}

Why3 uses the $\sum_{i=1}^{n - 1} i$ from the induction hypothesis and:

\begin{aligned}
n + \frac{(n - 1)n}{2} = \frac{n(n + 1)}{2}
\end{aligned}

 # 5\. Where is the implication `P(n-1) → P(n)`?

 This is the really important part.

 $$

```

 > Assuming `P(n-1)`, prove `P(n)`.

P(n-1) \vdash P(n)

 $$
P(n-1) \rightarrow P(n)

Yes — **Why3 is doing the same logical thing as mathematical induction**, but there is an important distinction between:

 - **assuming** `P(n-1)` inside the induction step, and

 ### The key idea

 When Why3 verifies your recursive lemma

```
let rec lemma sum_formula_aux (n: int)
  requires { n >= 0 }
  ensures { sum n = div (n * (n + 1)) 2 }
  variant { n }
=
  if n = 0 then
    ()
  else
    sum_formula_aux (n - 1)
```

 it is essentially proving the implication

 $$
P(n-1) \Longrightarrow P(n)
$$

 in the recursive branch.

 It is **not** saying:

 > "I know that `P(n-1)` is true because I have already independently proved it."

 Instead, it says:

 > "Suppose `P(n-1)` is true. Under that assumption, I can prove `P(n)`."

 That is exactly the **induction step**.

 ## But then how can `P(n-1)` be used?

 This is the crucial part.

 Suppose we're proving:

 $$
\forall n\ge0,\ P(n)
$$

 Mathematical induction says:

 1. Prove `P(0)`.
2. Prove\

   $$
   \forall n>0,\quad P(n-1)\Rightarrow P(n).
   $$

 Notice that step 2 **does not prove `P(n-1)`**.

 It proves the conditional:

 $$
P(n-1)\Rightarrow P(n).
$$

 Then, **together with the fact that `P(0)` is true**, we can derive:

 $$
P(1)
$$

 because:

 $$
P(0)\Rightarrow P(1)
$$

 and we already have `P(0)`.

 Then:

 $$
P(1)\Rightarrow P(2)
$$

 and now we already established `P(1)`, so we get `P(2)`.

 And so on.

 ### So is `P(n-1)` actually true?

 **Yes, ultimately.**

 But **not because the induction step assumes it**.

 It becomes known to be true because the whole induction argument establishes the sequence:

 $$
P(0), P(1), P(2), P(3), \ldots
$$

 The induction hypothesis is a _temporary assumption_ used to prove the implication.

 Why3 can use the **postcondition of the recursive call**:

```
sum (n - 1)
=
div ((n - 1) * n) 2
```

 That is exactly:

 $$
P(n-1).
$$

 But where does that fact come from?

 **From the recursive call itself.**

 And why is Why3 allowed to trust the recursive call?

 Because Why3 is verifying the recursive function using **induction on the variant**:

```
variant { n }
```

 The recursive call has a smaller argument:

 $$
n-1 < n
$$

 when `n > 0`.

 So Why3's termination/induction mechanism says, essentially:

 > To prove the lemma for `n`, I may use the lemma's specification for a smaller value `n-1`.

 That is the induction hypothesis.

---

 # Think of it this way

 Imagine Why3 is proving your lemma for some arbitrary `n > 0`.

 It has:

```
Goal:

sum(n) = div(n*(n+1), 2)
```

 The recursive call gives it:

```
IH:

sum(n-1) = div((n-1)*n, 2)
```

 Now unfold `sum(n)`:

```
sum(n) = n + sum(n-1)
```

 So the goal becomes essentially:

```
n + sum(n-1)
    =
div(n*(n+1), 2)
```

 Then Why3 substitutes the induction hypothesis:

```
n + div((n-1)*n, 2)
    =
div(n*(n+1), 2)
```

 and the arithmetic solver proves that.

 So the logical structure is:

```
             assume P(n-1)
                  │
                  ▼
          prove P(n)
```

 The recursive call is the mechanism that supplies `P(n-1)` **under the induction hypothesis**.

 # And what about `n = 0`?

if n = 0 then

```

 Why does `()` prove the postcondition?

```
n = 0
```

 and therefore the postcondition

```
sum 0 = div (0 * (0 + 1)) 2
```

 reduces to:

```
0 = 0
```

 So the base case establishes:

 $$

$$

 # The subtle but extremely important distinction

 You asked:

 > "You told me P(n-1) is not proven but it is assumption (as it was true, but without proving). IS it true?"

 The most precise answer is:

 ### During the induction step:

 `P(n-1)` is **assumed**, not independently proved.

 ### In the complete induction argument:

 `P(n-1)` is **justified by the induction principle**, ultimately because the base case and all previous induction steps establish it.

 So don't think:

 > "Why3 assumes a possibly false statement and therefore magically proves the theorem."

 Think:

 > "Why3 proves that if the theorem holds for a smaller argument, then it holds for this argument. The recursive structure plus the base case makes that implication an induction proof."

---

 ## A concrete example: `n = 3`

 Imagine we want:

 $$
P(3).
$$

 The induction step says:

 $$
P(2)\Rightarrow P(3).
$$

 We don't prove `P(2)` _inside the proof of `P(3)`_. We use it.

 But where did `P(2)` come from?

 From the previous induction step:

 $$
P(1)\Rightarrow P(2)
$$

 and `P(1)` came from:

 $$
P(0)\Rightarrow P(1)
$$

 and `P(0)` came from the base case.

 So:

```
P(0)                         ← base case
 │
 ▼
P(1)                         ← induction step
 │
 ▼
P(2)                         ← induction step
 │
 ▼
P(3)                         ← induction step
```

 Why3 compresses this whole potentially infinite-looking chain into the **recursive induction principle**.

---

 ## One more important correction to the phrase "it is not proven again"

 When I previously said:

 > "`P(n-1)` is not proven again."

 A more precise wording would be:

 > **`P(n-1)` is not proved as a separate obligation inside the proof of `P(n)`; it is supplied as the induction hypothesis.**

 That doesn't mean `P(n-1)` is ultimately unproven.

 It means **the current induction step is not responsible for establishing it**.

 This is exactly how ordinary mathematical induction works.

 Your intuition here is correct: **Why3's recursive lemma is implementing the same fundamental induction idea.**
