* Profiling Haskell in Windows

To profile your Haskell application on Windows w/ stack currently
(due existing bug?) you must:

#+BEGIN_SRC bash
C:\prj> stack build --profile
C:\prj> stack exec -- prj-exe --RTS +RTS -p -RTS [other options of app]
#+END_SRC

This will produce .prof file in current directory. You can add ~-h~ and
~-hy~ to ~-p~ to get info about heap/allocations. To produce .ps file use:

#+BEGIN_SRC bash
C:\prj> hp2ps -c your-hp-file-name
#+END_SRC

Then open generated .ps file in SumatraPDF and analize that.. -)
