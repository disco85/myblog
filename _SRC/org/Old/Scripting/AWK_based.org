* AWK based

LAWK is the simple literate programming tool for personal usage (no collaboration features).
For collaboration nanolp can be used [[https://github.com/bapcyk/nanolp][see]].

Input files are markdown, output - any one. Supports non-ASCII, Windows. Does not support
spaces and other special chars in paths. Source is [[https://github.com/bapcyk/lawk][here]].

Good feautures are:

- very clean syntax of definition, pasting, writing named chunks
- simple dependencies (awk, mkdir, rm, make) - available for Windows too
- no installation (only copy source somewhere)
- markdown input format
- no special syntax for code chunks
- ctags tag file generation (unsorted)
