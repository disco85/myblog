* Download all files by mime type

Download files of some types from URL:

#+BEGIN_SRC bash
wget -A ps,djvu -m -p -E -k -K -np -nH -L -l <DEEP> -e robots=off URL
#+END_SRC

all /.ps, /.djvu will be saved in own directories, but without host folder.
